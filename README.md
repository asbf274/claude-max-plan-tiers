## 升级前先搞懂：三层限额怎么运作

Claude 的用量不是一道简单的总量墙，而是三层结构叠在一起：

1. **5 小时会话窗口**：滚动计算，窗口过了自动恢复。官方给的规划参考是——短对话、低算力模型的前提下，Max 5x 每 5 小时至少 225 条短消息，20x 大约 900 条。
2. **跨模型周上限**：所有模型共享，每周在固定时间重置。重置时间固定，不随你开始使用或订阅的时间变化，在设置的 Usage 页面可以查看。
3. **按模型单独计算的上限**：社区反馈里普遍提到 Opus 这类高算力模型有单独的周上限，默认挂着 Opus 跑会更快碰到这条线。

第三方整理的参考值更直观一些：Pro 每个 5 小时窗口约 45 条 Opus 或 225 条 Sonnet 消息，Max 5x 约 225 条 Opus / 1,125 条 Sonnet，Max 20x 约 900 条 Opus / 4,500 条 Sonnet。注意这些全是估算——长上下文、附件、Research 任务和 Claude Code 会话的消耗都远高于短消息。

> 20x 是把天花板抬高 4 倍，不是把天花板拆掉。5 小时窗口和周上限在 20x 上依然存在，官方也保留在高峰期做额外调整的权力。

## 哪些信号说明你该从 5x 升到 20x

升级的关键词是**并行度**。对照下面五个问题，命中两个以上就该认真考虑 20x：

1. 你会同时开不止一个 Claude Code 会话吗？
2. 你会把任务丢给智能体长时间无人值守地跑吗？40 分钟的自主运行，消耗远大于 40 分钟有监督的来回对话。
3. 你用 agent teams 吗？按官方给的参考数字，队友以 plan 模式运行时整组消耗约是普通会话的 7 倍，因为每个队友都带自己的上下文。
4. 你默认用 Opus，而不是需要时才切过去吗？Opus 烧额度的速度比 Sonnet 快好几倍，还有单独的周上限。
5. 你的代码仓库很大，智能体每次动手前要读大量文件吗？上下文体积对消耗的影响比会话时长更大。

五个全是否，5x 基本够用，省下的 1,200 美元年费是真金白银；三个以上是，撞限打断工作的损失会很快超过差价。

还要提前有个心理准备：体感增幅可能没有数字那么大。一位两档都用过的用户在韩国 Claude 用户社区分享过自己的经历——用 5x 时主要挂 Opus，需要围着 5 小时限制安排会话、提前收尾、把上下文存进记忆，即便这么省着用，周限额还是 4 到 5 天就见底；升到 20x 之后，5 小时限制再也没碰过，但按他自己的工作流，周用量体感只涨了大约 1.5 倍，够不到账面的 4 倍。这个数字因人而异，对话长度、模型组合、工作节奏都会影响，但“周上限不会按 4 倍放大”这个方向是确定的。

## 升级怎么操作，钱怎么扣

操作本身不复杂：登录后在左下角头像进入设置，选 Upgrade plan，挑 Max 20x，付款后立即生效。账单规则里有几条容易踩坑的：

- **5x 升 20x 按比例补差价**：只为本账期剩余天数收按比例折算的费用，不是立刻扣一整个 200 美元。如果订阅含每月 API 额度，差价对应的额度会按比例立刻发放，之后每个账期按新档发放。
- **降级不退当期差价**：从 20x 降回 5x 或降到 Pro，当前档位权益保留到期末，低档位下个账期才生效。
- **年付 Pro 转 Max 有余额抵扣**：如果年付 Pro 的剩余价值高于 Max 月费，差额会以账户余额形式发放，抵扣后续订阅费。前提是两次购买的账单地址一致；地址变过，就只能等 Pro 到期再重新订阅。
- **通过 Google Play 升级是另一套逻辑**：按新套餐全价扣款，旧套餐未用完的价值折算成新套餐的额外天数，续期日会比整月晚几天。

## 常见问题

**Max 20x 是无限用量吗？**
不是。20x 是 Pro 每 5 小时会话额度的 20 倍，5 小时窗口、跨模型周上限、按模型的上限全部保留，官方也可能在高峰期做额外调整。

**升到 20x 之后还能降回来吗？**
能。两个档位都是月付订阅，当期权益用到账期结束，下个周期生效降档。先按 5x 跑一个月、用 /usage 数一数撞限次数，是判断要不要 20x 最省钱的方法。

**Claude Code 的用量和聊天共享吗？**
共享。同一个订阅额度池覆盖网页端、桌面端、手机端、Claude Code 和后台多步任务，快到上限时产品内会有提醒。这也意味着聊天聊得凶，智能体能用的额度就变少。

**Max 有折扣吗？**
没有长期折扣。官方偶尔做限时促销，一般通过官方渠道公布，客服无法发放单独折扣码。手机应用商店的价格可能与网页端不同。

**Max 订阅送 API 额度吗？**
送。Max 和 Team 计划包含每月的 Claude API 额度，中途升级时按比例折算立刻发放，之后每个账期按新档发放。
